Rihla lite: Grandma's Quarter, Year 1 units 1 to 5, with no AI model and no speech server.

Put this folder on any HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages). On the iPad, open the address in
Safari, tap Share, then "Add to Home Screen". After that first visit it starts from the home screen and works offline.

Without HTTPS it still plays (for example from a computer on the same Wi-Fi: npm run lite:serve), but it won't work offline.
Build f2cb370ace.
